# Weaviate 
<Enterprise />

## Overview

Once the Weaviate integration is configured, the configured vector store instance will be available for use in the [Vector Store](/docs/components/vectorStore.mdx) component.

## Configuring Weaviate vector store integration

| Parameter              | Required |  Description                                                                                                                                            |
|------------------------|----------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| Integration name       | true     | Unique name for the integration                        |
| URL                    | true     | URL of the vector store                                |
| API Key                | false    | API key used to authenticate with the vector store     |
