## Description
Table source component is automatically generated based on the Flink Table API integration definition. The name of the component will be `Integration-name Table`. You can only ingest whole database tables or files using this component; check the [Table API integration](/docs/integrations/tableAPI.mdx) for more information.

This component does not take any parameters.
